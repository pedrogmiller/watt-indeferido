# Watt Indeferido

Consola IPP — TRCs alcançados (Pego, Ferreira do Alentejo, Évora).

https://wattindeferido.pt/
https://pedrogmiller.github.io/watt-indeferido/

A consola jogável do MVP está em `index.html`. GitHub Pages publica a raiz de `main`; o `CNAME` é `wattindeferido.pt`. Entrada do loop: `index.html?mvp=1`.

O pacote de conteúdo do Correio (MVP Iteration 1) está em dois sítios, com os mesmos ficheiros (não é um symlink):

- [`events/`](events/) — pacote para edição (skeletons, skins, se-sheets, SCHEMA, MVP)
- [`content/events/`](content/events/) — o que a consola carrega (`EVENTS_BASE = 'content/events'`)

Ver [`events/README.md`](events/README.md), [`events/SCHEMA.md`](events/SCHEMA.md) e [`events/MVP-ITERATION-1.md`](events/MVP-ITERATION-1.md).
